# 3. Funding Pots et dépenses

Les Funding Pots contiennent les ressources affectées à des dépenses ou paiements. Les appels vérifient les rôles, les montants et les autorisations du domaine.

Ce chapitre relie le mécanisme aux contrats concernés et explicite les invariants utiles à un intégrateur.
