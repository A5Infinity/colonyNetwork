# 2. Réputation

La réputation évolue selon les actions et les domaines de compétence. Elle sert à pondérer certaines décisions sans être un simple solde transférable.

Ce chapitre relie le mécanisme aux contrats concernés et explicite les invariants utiles à un intégrateur.
